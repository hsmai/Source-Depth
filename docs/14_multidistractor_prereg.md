# PART D (b) 다중 distractor — 사전 등록

작성: 2026-08-13, **결과 관측 전**. 브리프 PART D "실패 시 대응 (b) distractor 2장으로 증가"의 실행.

## 질문

오염은 **모델 크기**보다 **경쟁하는 출처의 수(N)** 에 민감한가?

7B에서 ①(문제 실재)이 사실상 FAIL(오염 +2.0%p)했다. 이것이 (a) 7B가 근본적으로 오염되지
않아서인지, (b) **N=2(원본+방해1장)가 너무 쉬운 설정이어서**인지를 가른다.

이 답이 이후 방향 전체를 결정한다 — 멀티인풋(멀티이미지·옴니·롱비디오)으로 확장하는 근거가
"출처가 많을수록 오염이 심해진다"이기 때문이다.

## 설계 (scripts/14_multi_distractor.py, 기존 pairs.csv 재사용)

| 조건 | 구성 | 정답 |
|---|---|---|
| **M3-leak** | [원본, 방해1(질의 객체 O), 방해2(질의 객체 O)] | no |
| **M3-ctrl** | [원본, 방해1(질의 객체 X), 방해2(질의 객체 X)] | no |

개입 조건: S(1장) / M(3장 무개입) / T0 / T4 / T8 / T16
모델: 7B 먼저(문제가 사라진 쪽), 이어서 3B(비교 기준선)

## 측정 지표

**오염 = acc(M3-ctrl) − acc(M3-leak), 조건 M.**
정답·이미지 수가 동일하고 **방해 이미지에 질의 객체가 있는지만 다르다** → 단일 조작 대조.

### 기준선 (1-distractor, 이미 측정됨, 조건 M)

| | 셀1(유출) | 셀3(대조) | 오염 |
|---|---|---|---|
| 3B | 0.7200 | 0.9800 | **+26.0%p** |
| 7B | 0.9667 | 0.9867 | **+2.0%p** |

## 판정 기준 (사전 고정)

**주 종점: 7B의 오염 (distractor 2장)**

| | 조건 | 해석 |
|---|---|---|
| **통과** | ≥ **10.0%p** 이고 McNemar **p < 0.01** | 오염은 N에 민감. 멀티인풋 확장의 근거 확보 |
| **부분 통과** | ≥ **6.0%p** 이고 **p < 0.05** | 방향은 맞으나 효과 작음. N을 더 키운 추가 측정 필요 |
| **실패** | < 6.0%p 또는 유의하지 않음 | 오염 축은 스케일에서 소멸. **환각 기여를 버리고 효율 단독으로 전환** |

10.0%p 근거: 7B 기준선 2.0%p의 5배. 3B의 1-distractor 오염(26.0%p)의 약 40%.

**부 종점**
1. 3B에서 오염이 26.0%p보다 **증가**하는가 (N 단조성). 천장 효과 가능성 있음 — 증가 없어도 주 종점을 무효화하지 않는다.
2. T0/T4에서의 회복률이 1-distractor 대비 유지되는가.

## 사전에 못박는 해석 제약

1. **이 설계는 오염(한 방향 유출)을 측정하지, 일반 판별력을 측정하지 않는다.**
   M3-leak·M3-ctrl 모두 정답이 "no"이므로 정확도 = no 응답률이다. 대조군이
   "이미지가 3장이면 yes를 더 말한다"를 배제하므로 **오염 주장은 유효하나**,
   "판별력이 좋아졌다/나빠졌다"는 주장은 **이 데이터로 하지 않는다.**

2. 개입(T0~T16) 효과를 정확도로 논할 때는 **반드시 최적 임계값·AUC를 함께 보고**한다.
   (이전에 7B에서 +5.0%p가 임계값 보정 후 +0.17%p로 사라진 전례)

3. 실패 시 **벤치마크를 갈아타지 않는다.** 실패는 실패로 보고하고 효율 단독 트랙으로 전환한다.
