# 판별력 손상은 출처 수에 비례하는가 — 사전 등록

작성 2026-08-13, **결과 관측 전**. 실행 스크립트 `scripts/17_scale_auc.py`.

## 왜 이 측정인가

직전 실험(`docs/14`)의 주 종점이 실패했다 — 7B에서 누출은 출처 수를 늘려도 커지지 않았다
(+2.0 → +2.7%p, p=0.28). 그러나 사후 분석(`docs/15`)에서 **그 지표가 한쪽 방향만 보고
있었음**이 드러났다. 7B의 실패 모드는 누출이 아니라 **과잉 억제**이고, 임계값 무관
지표(AUC)로 보면 7B에서도 판별력 손상이 유의하다 (ΔAUC(M−S) = −0.0269, CI [−0.040, −0.014]).

직전 설계는 양쪽 그룹이 모두 gt=no라 **AUC를 계산할 수 없다.** 그래서 정작 지금 가장 알고
싶은 것 — **"7B의 판별력 손상도 출처 수에 비례하는가"** — 를 답하지 못한다.
이 실험은 그 하나를 위해 설계됐다.

## 설계

**문항** (n=300, gt 균형):

| | 출처 | 정답 | 방해 이미지 | 압력 방향 |
|---|---|---|---|---|
| 셀1 | pairs.csv | **no** (150) | 질의 객체 **포함** | "있다"고 말하게 |
| 셀2 | pairs.csv | **yes** (150) | 질의 객체 **미포함** | "없다"고 말하게 |

양쪽 모두 방해 이미지가 **오답 방향으로** 압력을 준다 → 판별력에 최대 부하.

**출처 수** N ∈ {1, 2, 3}. 방해 이미지는 **중첩** 구성(N=1의 방해가 N=2·3에도 포함)이라
N 외의 변수가 바뀌지 않는다.

**조건**: `S`(1장 단독, N 무관 1회) / 각 N에 대해 `M`(무개입) · `T0`(전층 차단) · `T4`(4층부터)
→ 300 × 10 = 3,000회/모델. 7B·3B 각각.

## 주 종점 (사전 고정)

**7B에서, AUC(M, N=3) − AUC(M, N=1).** 대응 부트스트랩 2000회, 95% CI.

| | 조건 | 해석 |
|---|---|---|
| **통과** | **≤ −0.020** 이고 CI가 0 배제 | 판별력 손상이 출처 수에 비례. **멀티인풋 확장의 근거가 7B에서 확보** |
| **부분 통과** | **≤ −0.010** 이고 CI가 0 배제 | 방향은 맞으나 약함 |
| **실패** | CI가 0 포함, 또는 부호가 반대 | 7B에서 손상은 N과 무관. **멀티인풋 확장 근거 없음 — 소형 모델 한정으로 범위 축소** |

−0.020 근거: 7B의 N=1 손상이 ΔAUC(M−S) = −0.0269였다. N을 3배로 늘려 그만큼이 한 번 더
쌓이면 −0.02 수준이다. 즉 "손상이 대략 배가된다"는 최소선.

## 부 종점

1. **3B에서 동일 지표.** 3B는 누출 기준으로 이미 N 비례가 확인됐다(+26.0 → +42.0%p).
2. **ΔAUC(T0 − M)** 이 각 N에서 유의하게 양수인가 — 회복이 N이 커져도 유지되는가.
3. 회복률 = ΔAUC(T0−M) / ΔAUC(S−M) 의 N에 따른 변화.

## 해석 제약 (사전 고정)

1. **주 지표는 AUC다.** 고정 임계값 정확도도 보고하되 판정 근거로 쓰지 않는다.
   (7B에서 +5.0%p가 임계값 보정 후 +0.17%p로 사라진 전례, 그리고 직전 실험이 지표
   때문에 현상을 놓친 전례)
2. **T0·T4는 오라클 조건이다.** 어느 이미지가 방해인지 알려준 상태의 상한이며,
   컨트롤러를 포함한 실현 가능 성능이 아니다. 회복률을 방법 성능으로 보고하지 않는다.
3. **실패 시 벤치마크를 갈아타지 않는다.** 실패는 실패로 보고하고, 범위를 소형 모델로 축소한다.
4. 부 종점 결과로 주 종점 판정을 뒤집지 않는다.

(사전 통과선 −0.020의 약 9배)

참고(판정 근거 아님) 고정 임계값 정확도: S=0.8167 / M1=0.6767 · M2=0.5600 · **M3=0.4600**
→ 방해 3장이면 우연(0.50)보다 낮아지고, T0에서 0.8200으로 복귀.

## 인과 해석이 성립하는 이유

M과 T0은 **같은 이미지가 물리적으로 모두 입력에 들어있고**, 차이는 방해 이미지의 KV가
0층부터 보이는지 여부뿐이다. 따라서 손상의 원인은 이미지의 존재가 아니라
**거기에 attention이 닿는 것**이다. T4(4층부터 차단)도 T0과 사실상 동일하다.

**단 T0·T4는 오라클 조건**(어느 것이 방해인지 알려준 상태)이며, 컨트롤러를 포함한
실현 가능 성능이 아니다 — 사전 등록된 해석 제약 그대로.

## 두 스케일 대조 (확정)

| | 무관 입력 1장의 손상 | N=3일 때 | N에 비례? | 차단 회복 |
|---|---|---|---|---|
| **3B** | −0.2100 (0.908 → 0.698) | **−0.3865** (→ 0.521, **우연**) | **강하게 예** | **99%**, N 무관 |
| **7B** | −0.0343 (0.903 → 0.869) | −0.0293 (→ 0.874) | **아니오** | 74~88% |

## 판정 요약

- **손상은 두 스케일 모두 실재하고 차단으로 회복된다** (모든 N에서 CI 0 배제).
- **손상이 출처 수에 비례하는 것은 3B에서만.** 7B의 손상은 방해 수와 무관한
  **고정 비용**(멀티이미지 모드 진입 비용)이며 잡음의 양에 비례하지 않는다.
- 3B와 7B의 손상 크기는 **약 6~13배** 차이.

사전 등록된 실패 경로에 따라: **멀티인풋 확장의 근거는 7B에서 확보되지 않았고,
연구 범위를 소형 모델로 축소한다.** 벤치마크는 갈아타지 않는다.
