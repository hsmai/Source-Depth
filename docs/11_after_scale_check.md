# 7B 결과 이후 — 연구 진단과 방향 재설정

> 작성 2026-08-12. 야간 확장 실험(7B 재현·차등 배분·순서 뒤집기·CLIP·multi-distractor) +
> 선행연구 웹 검증(3-agent) 결과 종합.

## 0. 한 문단 요약

7B에서 POPE 오염이 사라진 것은 **벤치마크의 해상도 한계이지 현상의 소멸이 아니다**(문헌 증거 다수, §2).
그리고 오염과 **무관한** 두 핵심 주장 — 질문 유형별 최적 depth의 상이함, 동일 예산에서 배분의 우위 —
은 **3B·7B 양쪽에서 재현됐다**(§1). 따라서 연구는 죽지 않는다. 다만 **주장의 축을
"환각 완화"에서 "질문 조건부 계산 배분"으로 옮기고**, 오염은 두 번째 증거로 배치해야 한다.
남은 진짜 병목은 **컨트롤러**다(§3).

## 1. 야간 실험 결과 (전부 실측)

### 1-1. ★ 동일 예산에서 배분이 결정적 — 두 스케일 모두 (fig5)

같은 "이미지-레이어 예산"을 배분만 달리한 통제 비교:

| 모델 | 배분 방식 | 절감 | 정확도 | 차이 |
|---|---|---|---|---|
| **3B** | 차등 J4x28 (32+8) | 50.5% | **0.837** | **+28.7%p** |
| | 일괄 VTW16 (20+20) | 50.5% | 0.550 | |
| **7B** | 차등 J4x28 | 38.9% | **0.802** | **+8.7%p** |
| | 일괄 VTW16 | 38.9% | 0.715 | |

차단 없음(M) 기준선은 양쪽 다 0.790. 즉 **차등 배분은 기준선보다 정확하면서(3B +4.7%p, 7B +1.2%p)
계산을 40~50% 아낀다.** 이것이 현재 가장 강한 수치이고 오염 유무와 무관하다.

### 1-2. ★ 질문 유형별 최적 depth 상이 — 두 스케일 모두 (fig6)

R1셀("두 이미지 모두에 X가 있나?", 정답 '아니오' — 2번 이미지를 반드시 봐야 함):

| | 차단 없음 | 4층 차단 | 낙폭 | 전환 구간 |
|---|---|---|---|---|
| 3B (36층) | 0.760 | 0.250 | **−51.0%p** | L16–24 (44–67% depth) |
| 7B (28층) | 0.950 | 0.540 | **−41.0%p** | L12–20 (43–71% depth) |

같은 개입이 단일이미지 질문에서는 **무해하거나 이득**(3B +21%p, 7B −0.7%p)인데 비교 질문에서는 붕괴.
**전환 구간이 두 모델에서 동일한 상대 깊이(≈43–70%)** — 스케일 불변 구조.

### 1-3. 컨트롤러 — 얕은 층 신호는 위치 편향으로 판명

순서 뒤집기 대조(관련 이미지를 2번 자리로):

| layer | 원본 | 뒤집기 | 양쪽 동시(min) |
|---|---|---|---|
| 8 | 0.998 | **0.002** | 0.443 |
| 12 | 1.000 | 0.002 | 0.480 |
| 20 | 1.000 | 1.000 | 0.617 |
| **22** | 1.000 | 1.000 | **0.882** |

→ 얕은 층의 99.8%는 "첫 번째 이미지 head". **위치 무관 신호는 layer 20–22에서 처음 나타난다(88.2%)** —
그리고 이 구간은 §1-2의 전환 구간과 일치. 모델이 질문↔이미지를 결합하는 지점.

### 1-4. CLIP 베이스라인 — 외부 선택기는 이 문제를 못 푼다 ✅

| 지표 | 값 |
|---|---|
| 전체 식별률 | **0.505** (무작위 수준) |
| CLIP이 원리적으로 풀 수 있는 셀(2·3)만 | 0.593 |
| 추가 비용 | 문항당 +10.05ms (별도 모델 forward) |

이유: 셀 1·4는 방해 이미지에도 질의 객체가 **실제로 있다**. CLIP은 객체 유사도만 보므로
"질문이 **첫 번째** 이미지를 가리킨다"는 지시를 반영할 수 없다. → **"CLIP 쓰면 되지 않나"에 대한 실측 반박.**

### 1-5. 현실적 작동점 (layer 22에서 판단 후 차단)

| 모델 | 조건 | 절감 | 정확도 | 동일 절감 일괄 대비 |
|---|---|---|---|---|
| 3B | J20x28 | 30.3% | 0.812 | +3.8%p (VTW24 0.773) |
| 3B | J22x28 | 27.8% | 0.810 | — |
| 7B | J20x28 | 13.0% | 0.790 | −0.2%p |

→ oracle 상한(50.5%/+28.7%p)의 절반 수준. **"판단 가능 시점이 개입 유효 시점보다 늦다"는
trade-off가 정량 확정됨.** 이것이 Phase 1의 1순위 과제.

### 1-6. α-knob (오류율 보증 배분)
정확도 무손실 조건에서 절감 21.2%(문항 60% 차단). 단 layer-8 신호 기반이라 **사실상 oracle** —
위치 편향 head를 썼기 때문. layer-22 신호 기반 재계산 필요 (한계로 명시).

## 2. "7B에서 오염이 없다"에 대한 문헌 판정 — (A) 벤치마크 한계

3-agent 웹 검증 결과, **(B) 스케일 소멸을 지지하는 1차 문헌 증거는 하나도 없었다.**

| 증거 | 내용 | 출처 |
|---|---|---|
| **FOCUS 부록 D.1** | Qwen2.5-VL-**7B** single→multi 정확도 **0.738 → 0.634 (−10.4%p)**. Qwen3-VL-8B −8.6%p. (3B는 −37.0%p) — "소형 모델 아티팩트가 아님"을 검증할 목적의 부록 | arXiv 2508.13744 |
| **FOCUS Table 1** | 같은 7B가 easy 벤치(VisMin-Easy 92.65)에선 개입 이득 −0.08, hard 벤치(Winoground)에선 39.75 → **58.50 (+18.75%p)**. 효과는 파라미터 수가 아니라 **벤치 headroom의 함수** | 동일 |
| **FOCUS Table D2** | **30B MoE**에서도 잔존 (+3.39%p) | 동일 |
| **MVH-Bench Table 2** | Qwen2.5-VL-7B의 **Adversarial Error Ratio 86.98% / 94.13%** — 오답의 대부분이 '다른 이미지에서 유래'. 우리 flip 개념과 동일한 지표가 7B에서 대규모로 측정됨 | arXiv 2603.23934 |
| **MVH-Bench Table 1** | **GPT-4o q-Acc 32.04/23.43, Claude 4.5 Sonnet 13.61/23.61** — 프론티어 모델도 붕괴 | 동일 |
| **MIBench Table 4** | **우리와 거의 동일한 프로토콜**(POPE + 객체 포함 distractor 1장): LLaVA-1.5 91.8→31.6, Qwen-VL 89.2→26.8 (−60pt급). 반면 멀티이미지 학습된 Mantis는 91.2→83.6(−7.6pt) → **결정 변수는 파라미터 수가 아니라 멀티이미지 학습 노출** | arXiv 2407.15272 |
| **MMNeedle (NAACL'25)** | 이미지 수 M=1→10에서 index accuracy: GPT-4o 99.0→87.2, LLaVA-Llama-3(8B) 93.7→**0.1** | arXiv 2406.11230 |
| **POPEv2** | Qwen2-VL 2B 91.04 > 7B 88.10 > **72B 82.12** — 스케일이 커질수록 오히려 악화 ("Image Speaks Louder than Model Size") | arXiv 2508.04567 |

**결론: (A) 우세 + (B) 부분 성립.** 효과 크기의 스케일 감쇠는 실재하지만(3B −37%p → 7B −10.4%p),
소멸은 아니다. 우리 7B null은 **POPE+무관 distractor 1장이 7B에게 변별력이 없기 때문**
(우리 실측 셀1 단일 0.947 = 공개 보고치 분포 최상단, headroom 5%p).

## 3. 그래서 연구는 어떻게 되는가

### 살아남는 기여 (우선순위 순)
1. **질문 조건부 per-image 계산 배분** — 동일 예산에서 +28.7%p(3B) / +8.7%p(7B). 오염 무관, 양 스케일 재현
2. **최적 depth가 질문 유형에 따라 정반대** — 고정 정책 불가의 원리적 근거, 양 스케일 재현, 상대 깊이 불변
3. **결합(binding) 발생 depth의 국재화** — 관계 통합·오염·위치 무관 신호가 모두 같은 구간(상대 깊이 43–70%)
4. **cross-image 오염 완화** — 3B에서 직접 실증(회복 81%), 7B는 문헌상 harder 벤치에서 존재

### 프레이밍 전환 권고
- **Before**: "멀티이미지 환각을 계산을 줄이며 완화한다"
- **After**: "**멀티이미지 LVLM에서 계산 배분은 효율 변수가 아니라 정확도 변수다** — 질문에 따라
  이미지별 실행 깊이를 다르게 주면 같은 비용에서 더 정확하고, 부수적으로 출처 오염도 줄어든다"

### "어려운 task로 갈아탄다"는 비판에 대한 방어
1. POPE는 **메커니즘 격리용 최소 통제 세팅**으로 선택한 것이지 최종 평가 벤치가 아니다 (브리프 B-1)
2. distractor 증설은 **브리프 PART D에 사전 등록된 실패 대응 (b)** — 결과를 보고 정한 것이 아니다
3. 이동 대상(MVH-Bench)은 **제3자가 이 현상을 위해 만든 공개 벤치**이지 우리가 만든 것이 아니다
4. 7B가 POPE에 포화됐다는 것은 **우리 실측·공개 보고치·FOCUS의 VisMin-Easy 사례**로 독립 확인

### Phase 1 우선순위 (수정)
| # | 과제 | 이유 | 기간 |
|---|---|---|---|
| 1 | **위치 무관 컨트롤러** — layer ≤16에서 88%+ 신호 탐색 (attention 질량 외 feature: delimiter hidden state, cross-attention 패턴, entropy) | 유일한 진짜 병목. 실패 시 절감이 반토막 | 2주 |
| 2 | **MVH-Bench 이식** — binary yes/no라 현 파이프라인 그대로 재사용 가능. 7B baseline 64.10%로 headroom 35%p | 오염 축의 7B 실증 | 1주 |
| 3 | **실측 속도** — 커널 수준 compaction + ViT 단계 배분 | 이론 42% vs 실측 9.7% 격차 해소 | 2주 |
| 4 | multi-distractor(2장) 완주 + 이미지 수 스케일링 곡선 | MMNeedle·MIHBench가 예측하는 단조 악화 확인 | 진행 중 |

## 4. 미팅 대응 스크립트

**Q: "7B에서 안 나오면 의미 없는 것 아닌가?"**

> "저희도 그 결과를 보고 같은 걱정을 했고, 그래서 두 가지를 확인했습니다.
> 첫째, 문헌을 봤습니다. FOCUS 논문은 같은 Qwen2.5-VL-7B에서 single→multi 정확도가
> 10.4%p 떨어지는 걸 부록에서 따로 검증해 뒀고, MVH-Bench는 7B의 오답 중 87~94%가
> '다른 이미지에서 온 정보'라고 보고합니다. GPT-4o도 이 벤치에서 무너집니다.
> 즉 현상은 7B에서 사라지지 않습니다.
> 둘째, 저희 세팅을 봤습니다. 7B는 저희 POPE 문항 단일 이미지에서 94.7%를 맞힙니다.
> 천장에 붙어 있어서 오염이 드러날 여지가 없는 겁니다. 계측기의 해상도 문제입니다.
>
> 그리고 더 중요한 건 — **저희의 두 핵심 결과는 오염과 무관하게 7B에서도 재현됐습니다.**
> 같은 계산 예산에서 배분만 바꿔도 7B에서 8.7%p 차이가 났고, 질문 유형별로 최적 깊이가
> 정반대인 것도 그대로였습니다. 그래서 저희는 주장의 축을 '환각 완화'에서
> '질문 조건부 계산 배분'으로 옮기고, 오염은 두 번째 증거로 배치하려 합니다."
