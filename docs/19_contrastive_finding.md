# 대조 디코딩이 하드 차단과 단일이미지 상한을 모두 넘는다

2026-08-14. **사후(탐색적) 분석**, 기존 scale_auc 로그의 저장된 logit만으로 계산 — GPU 재실행 없음.

## 정의

`margin_CD = (1+β)·margin(T0) − β·margin(M)`
T0 = 방해 이미지 KV 전면 차단, M = 무개입. β=0 이면 T0 그대로.

## 결과 (AUC, n=300)

| | 3B N=1 | 3B N=2 | 3B N=3 | 7B N=1 | 7B N=3 |
|---|---|---|---|---|---|
| M (무개입) | 0.6978 | 0.6063 | 0.5213 | 0.8690 | 0.8740 |
| T0 (하드 차단) | 0.9058 | 0.9037 | 0.9041 | 0.8993 | 0.8957 |
| CD β=0.25 | 0.9251 | 0.9269 | 0.9355 | **0.9024** | 0.8947 |
| CD β=0.5 | 0.9366 | 0.9406 | 0.9521 | 0.9028 | 0.8910 |
| **CD β=1.0** | **0.9455** | **0.9474** | **0.9644** | 0.8952 | 0.8774 |
| CD β=2.0 | 0.9406 | 0.9444 | 0.9655 | 0.8444 | 0.8280 |

**단일이미지 상한 S = 0.9078 (3B) / 0.9033 (7B).**

3B에서 CD(β=1)는 **하드 차단(+0.060, CI [+0.038, +0.087], 유의)과 단일이미지 상한(+0.057)을
모두 넘는다.** 7B는 β를 키우면 오히려 손해 — 제거할 오염이 거의 없기 때문.

## 왜 상한을 넘는가

| 3B, N=3 | AUC |
|---|---|
| S (1장 단독) | 0.9078 |
| T0 | 0.9041 |
| **순수 차이 T0 − M** | **0.9370** |
| CD β=1 | 0.9644 |

**"방해 이미지를 뺐을 때 답이 얼마나 움직였는가"라는 차이 신호 자체가, 두 끝점 어느 쪽보다
강한 판별 정보다.** 많이 밀린 문항이 곧 틀릴 뻔한 문항이기 때문. 제거는 오염을 없애지만,
대조는 **오염의 크기를 증거로 쓴다.**

## 한계 — 정직하게

1. **forward 2회 필요** → 효율 이득 없음(오히려 2배). 이것은 **정확도 트랙**이지 효율 트랙이 아니다.
   하드 차단(T0)이 효율 트랙, CD가 정확도 트랙 — 서로 다른 지점.
2. T0는 **오라클**(어느 것이 방해인지 앎). CD도 같은 전제를 물려받는다.
3. β는 하이퍼파라미터. 3B 최적 ≈ 1.0, 7B ≈ 0.25. 자동 선택 미검증.
4. 사후 분석이며 사전 등록되지 않았다. 확정 전 독립 재현 필요.
