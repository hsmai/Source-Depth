# 42. 사진 수 N 대 지시 방식 — 탐색 파일럿 (사전 기록)

작성 2026-10-13, 실행 전. 스크립트 `scripts/43_index_vs_n.py`, 집계 `scripts/44_index_vs_n_analyze.py`.
**탐색 파일럿이다.** 문턱값으로 통과/불통과를 가르지 않으며, 교수님 승인 전이다. 자체 구성 문항(공개 벤치 아님)이다.

## 왜 하는가

참조 결속 프로브(docs/41)는 attention을 끊었을 때의 효과만 본다. 교수님의 첫 지적("큰 모델에서는 현상이 없다")에
개입 없이 답하려면, **아무것도 건드리지 않은 7B가 사진이 많아질 때 "k번째 사진"을 스스로 못 찾게 되는지**를 재야 한다.
같은 날 중간 로그(3B, 옛 문항 재실행분)에서 "Picture N:" 라벨이 3B의 서수 질문 손실 대부분을 메웠으므로, 라벨 유무도 함께 잰다.

## 설계

- Qwen2.5-VL-7B, 3B. 개입 없음(마스크 없음). 첫 토큰 yes/no margin. LM attention은 SDPA(메모리), 실패 시 eager로 되돌리고 기록.
- 문항 300개 = (anchor, obj) 150쌍 × 정답 yes/no 한 개씩. 방해 사진은 anchor가 없는 사진 중 **무작위**(obj 포함 여부는 자연 비율, 기록).
- N ∈ {2, 3, 5, 8, 10}, 같은 문항의 방해 사진을 앞에서부터 N−1장 쓰는 중첩 구성. 관련 사진 위치는 N마다 무작위.
- 조건: 단독(S) / 서수(ORD) / 내용(CON) / 라벨+서수(LBL_ORD) / 라벨+"Picture k"(LBL_PIC) / 라벨+내용(LBL_CON).
- 보고: N별 AUC·고정 임계 정확도·예 비율, N=10 대 N=2 차이와 라벨 효과의 문항 단위 bootstrap CI, 관련 사진 위치별 정확도.

## 미리 적어 두는 해석 기준

- "흥미롭다"고 말할 조건: 7B에서 ORD의 AUC가 N=2 대비 N=10에 0.10 이상 떨어지고(CI가 0을 배제), 같은 문항에서 라벨 조건의 하락이 그 절반 이하.
- 그렇지 않으면: "7B는 사진 10장까지 서수 지시를 스스로 유지한다"로 적는다. 이 경우 참조 결속 이야기는 개입했을 때만 성립하는 것으로 남는다.
- CON(내용 지시)의 하락은 관련 사진을 찾는 검색 난이도이며 문헌(Visual Haystacks)에 이미 있는 현상이다. 새 주장으로 쓰지 않는다.

## 한계

- 사진 수에 따른 위치 편향은 SoFA(CVPR 2025)가 이미 다뤘을 가능성이 높다(조사 중). 새로울 수 있는 부분은 라벨 유무와 지시 방식을 같은 문항에서 가른 것뿐이다.
- COCO 주석 오류, 보유 이미지 1,642장의 재사용, 첫 토큰 예/아니오, 한 모델 계열, 문구 한 종류.
