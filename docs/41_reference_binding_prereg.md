docs/40 §6의 E4("이미지 간 차단: 서수 지시 대 내용 지시 × 경계 토큰 포함/패치 전용")를 구체화한 것이다.

## 왜 하는가

기존 로그(pathway, pathway_swap, generalize)에서 "뒤 사진이 앞 사진을 못 보게" 하면
서수 지시 질문의 AUC가 3B 0.697→0.403, 7B 0.869→0.447로 떨어졌다(뒤집은 배치 0.800→0.568, 0.878→0.448).
서수가 없는 질문(any-of-3, all-of-3)에서는 0 ~ −0.055였다. **이 효과는 7B에서도 줄지 않는다.**

그러나 지금까지는
1. 마스크가 경계 토큰(vision_start/end)까지 끊었고,
2. 내용 지시 질문("…을 포함한 사진에서")에서는 한 번도 재지 않았으며,
3. 서수 질문과 내용 질문이 서로 다른 사진 세트였다.

따라서 "사진의 순번 정보가 이미지 간 attention으로 전달된다"는 아직 가설이다.

## 설계

- 모델: Qwen2.5-VL-3B, 7B. 첫 토큰 yes/no margin. 마스크는 prefill 단발 forward. 위치 id(M-RoPE)는 건드리지 않는다.
- PART A (서수, 2장): pairs.csv 적대 셀 300행 × 배치 2종(관련 앞 + "first" / 관련 뒤 + "second"). 단독 입력 2종(관련만, 방해만) 추가.
- PART B (내용 지시): anchor_items 600문항(K=2·3 각 300).
- PART C (서수 지시): **PART B와 같은 사진·객체·정답**, 질문만 "In the {first/second/third} image"로 교체.
- 조건: M / X_ALL / X_COLD(앞 사진의 경계만 가림) / X_COLP(앞 사진의 패치만 가림) / X_ROWD / X_ROWP(PART A)
  / XF{2,4,8,12,16}·XU{2,4,8,12,16}(PART A) / LBL_M·LBL_X_ALL("Picture i:" 라벨 템플릿).
- 통계: 문항 단위 paired bootstrap 2,000회, ΔAUC 95% CI. LBL_X_ALL은 LBL_M 대비, 나머지는 M 대비.

## 예측 (실행 전 고정)

| | 예측 | 판정 |
|---|---|---|
| P1 | 서수 지시에서 X_ALL은 AUC를 0.15 이상 낮춘다 — A_orig, A_swap, C_ordinal(K=2, K=3), 두 모델 모두 | 8개 설정 중 7개 이상에서 CI 상한 < −0.15 이면 성립 |
| P2 | 내용 지시(B_content)에서 X_ALL의 ΔAUC는 −0.05보다 나쁘지 않다 | 4개 설정(K×모델) 전부에서 CI 하한 > −0.05 이면 성립 |
| P3 | 붕괴를 재현하는 것은 X_COLD와 X_COLP 중 하나다 (방향 미지정·탐색) | 한쪽이 X_ALL 하락의 70% 이상, 다른 쪽이 30% 이하이면 "운반체 특정". 아니면 "중복 운반" |
| P4 | 라벨 템플릿에서는 서수 지시에서도 X_ALL이 무해하다 | LBL_X_ALL − LBL_M 의 CI 하한 > −0.05 (서수 설정 전부) |
| P5 | (기술) XU{L}이 X_ALL 하락의 70%를 재현하는 최소 L, XF{L}이 재현하는 최대 L | 판정 없음. 보고만 |

## 결과가 뜻하는 것

- **P1·P2 성립**: "이미지 간 attention의 필수 기능은 사진 순번 부여이고, 내용 지시에는 필요 없다"가 같은 사진 세트에서 확인된다.
  문헌의 부호 충돌(이미지 간 상호작용이 해롭다 대 이롭다)을 설명하는 축의 후보가 된다.
- **P1 실패(C_ordinal에서 안 무너짐)**: 기존 효과는 옛 300문항 한정 → 이 가설 폐기.
- **P2 실패(내용 지시도 무너짐)**: 순번 문제가 아니라 일반적 필요 → 가설 폐기, "섞임이 필요하다"로 되돌아감.
- **P4 성립**: 사진별 독립 인코딩이 라벨만으로 안전해진다는 뜻 → 격리·캐시류 방법에 대한 실용적 함의.
- **P4 실패**: 라벨이 있어도 모델은 이미지 간 attention으로 순번을 잡는다 → 격리류 방법은 서수 지시를 구조적으로 깨뜨린다.

## 한계 (미리 적어 둠)

- 적대 2셀 구성이라 AUC < 0.5는 "방해 사진의 답 쪽으로 기운다"를 뜻할 뿐, 자연 분포의 정확도가 아니다.
- 첫 토큰 예/아니오만 본다. 자유 생성에서의 지시 오류는 재지 않는다.
- Qwen2.5-VL 한 계열. 사진 2~3장. 경계 토큰이 다른 계열에서는 조건 정의가 달라진다.
- 마스크는 독립 인코딩을 흉내 낸 것이며 실제 캐시 재사용을 구현한 것이 아니다(위치 id 유지).
