# 경로 분해 결과 — "섞임"이 아니라 "읽기"였다

2026-08-14. `scripts/22_pathway_pilot.py`, n=300/파트, 3B·7B 각 2700건 완료.
사전 기록 `docs/18_pathway_prereg.md` 의 예측 P1·P2·P3 대조.

## PART 1 — 경로 분해 (AUC)

| | M | XIMG (img2→img1 차단) | READ (질문→img2 차단) | T0 (img2 전면) |
|---|---|---|---|---|
| **3B** | 0.6970 | **0.4030** | **0.9057** | 0.9057 |
| **7B** | 0.8690 | **0.4471** | **0.8993** | 0.8993 |

### ① READ ≡ T0 (차이 0.0000, CI [0,0])

causal 순서 [img1, img2, text]에서 img1은 img2를 볼 수 없다. 따라서 방해 이미지의 영향은
**질문 토큰이 그것을 읽는 경로 하나로만** 흐른다. 다른 채널이 존재하지 않는다.
동시에 4D mask 구현의 정확성 검증이기도 하다.

### ② 이미지 간 attention을 끊으면 크게 나빠진다 (3B −0.294, 7B −0.422)

**사전 예측 P1은 불성립**이지만, 방향이 설계 가설과 **반대**다:
- 설계 가설: "이미지 간 정보가 섞여서 환각" → 섞임을 끊으면 좋아져야 함
- 실측: 섞임을 끊으면 **크게 나빠짐**. 섞임은 도움이 된다
- 해악은 **읽기 단계의 출처 오귀속(source misattribution)**

→ **가설 문구를 정정해야 한다.** "정보 섞임" → **"읽기 단계 오귀속"**.
→ 개입 지점도 "표현 분리"가 아니라 **"읽기 경로 제어"**. 기존 T0가 이미 읽기 경로 개입이었다.

## PART 2 — need-all 질문에서의 고립 (AUC)

질문: "Is there {obj} in **any of these images**?" (3장, gt 균형 150/150)

| | M3 | ISO0 | ISO16 | ISO0 − M3 |
|---|---|---|---|---|
| 3B | 0.9888 | 0.9898 | 0.9896 | +0.0009 [−.0027, +.0047] |
| 7B | 0.9848 | 0.9826 | 0.9847 | −0.0022 [−.0106, +.0055] |

**P2 성립.** 앞단 selector가 원리적으로 불가능한 질문 유형에서도, 이미지끼리 서로 보지 못하게
해도 손해가 없다 — **통합은 텍스트 토큰이 수행한다.**

**한계**: 이 태스크는 AUC 0.99로 천장이다. 증거력이 약하므로 더 어려운 need-all 셋 필요.

## PART 3 — 이미지 간 attention이 필요한 경계 (정확도)

질문: "Is there {obj} in **both images**?"

| | R1 (img1만 보유) | R2 (img2만 보유) | RB (양쪽 보유) |
|---|---|---|---|
| 3B  M → ISO0 | 0.760 → 0.640 (**−12.0%p**) | 0.500 → 0.400 (−10.0%p) | 0.740 → 0.760 (+2.0%p) |
| 7B  M → ISO0 | 0.940 → 0.850 (**−9.0%p**) | 0.490 → 0.830 (+34.0%p) | 0.660 → 0.500 (**−16.0%p**) |

**비교 질문에서는 고립이 손해다.** 이미지 간 attention의 필요 여부는 **질문 유형이 정한다**:
"있나?"(any) → 불필요 / "둘 다?"(both) → 필요.

## 종합 — 새로운 그림

1. 방해 이미지의 해악은 **전부 읽기 경로**를 통해 흐른다 (다른 채널 없음, 인과적으로 확정)
2. 이미지 간 attention 자체는 **도움**이 된다 — 끊으면 크게 손해
3. 그 도움이 **필수**가 되는 지점은 비교(both) 질문
4. 따라서 올바른 개입은 "이미지 간 분리"가 아니라 **"질문 유형에 따른 읽기 경로 제어"**

이는 설계안의 method 후보 중 **neg attention으로 뒤쪽 layer에서 섞인 정보를 분리**한다는
방향이 전제부터 어긋남을 뜻한다. 분리할 대상이 문제가 아니었다.
