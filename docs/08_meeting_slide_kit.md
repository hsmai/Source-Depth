## Slide 2 — 이 연구가 성립하려면 무엇이 필요한가 [요청 1]

**[헤드라인]** 연구가 성립하려면 3가지가 정량으로 확인되어야 한다 — 기준은 실험 전에 등록하고 바꾸지 않았다

**[시각]** 3단 구조 다이어그램 (가설 → 필요한 증거 → 사전 등록 통과 기준):
| 필요한 증거 | 왜 필요한가 | 사전 등록 기준 |
|---|---|---|
| ① distractor가 답을 오염시킨다 | 문제가 실재해야 해결 가치가 있음 | Flip ≥ 10%p & 대조군은 절반 미만 (양방향) |
| ② 후반 layer KV 차단이 오염을 회복 | 제안 메커니즘이 실제로 작동해야 함 | M→T(0) 격차의 50%+ 회복, McNemar p<0.05 |
| ③ 얕은 attention으로 관련 이미지 식별 | training-free 컨트롤러의 재료 | layer 8 top-1 식별률 ≥ 80% |

**[텍스트]**
- 핵심 가설: 이미지 간 정보가 섞이는 유일한 통로 = layer별 self-attention → **depth = 혼합량**
- 판정 기준·실패 시 대응까지 실험 전 문서로 동결 (연구 노트 링크) — 결과 보고 기준을 바꾸지 않음

**[멘트]** 사전 등록을 강조 — "수치가 잘 나와서 기준을 맞춘 게 아니라, 기준을 먼저 정하고 수치를 냈습니다."

## Slide 3 — 실험 설계: 4셀 통제 + 10조건 [요청 2]

**[헤드라인]** 양방향 flip을 측정하는 4셀 설계 — "yes-bias"라는 대안 설명을 원천 차단한다

**[시각 1]** 4셀 2×2 표 (행: 정답 No/Yes, 열: distractor에 객체 포함/미포함):
```
                distractor에 객체 있음     없음
정답 No     |  셀1: leak 측정 (No→Yes)  |  셀3: 대조군
정답 Yes    |  셀4: 대조군              |  셀2: 역방향 leak (Yes→No)
```
각 셀 150문항 · POPE adversarial · COCO annotation으로 조건 검증

**[시각 2]** 입력 구성 그림: [이미지1=원본][이미지2=distractor] + "In the first image, is there a {object}?" → 정답은 이미지1 기준

**[시각 3]** 조건 축 다이어그램: S(단독) · M(2장, baseline) · T(L): L∈{4,8,12,16,20,24}에서 distractor KV 차단 · T(0)=완전 차단 상한 · T-rel(8)=**원본을** 차단하는 negative control

**[텍스트]**
- 설계 타당성 ①: 셀1(No→Yes)과 셀2(Yes→No)는 **반대 방향** — 단일 편향으로 두 방향 모두 설명 불가
- 설계 타당성 ②: oracle 세팅(관련 이미지를 알고 시작) — **가설 검증과 컨트롤러 성능을 분리**
- 설계 타당성 ③: negative control 내장 — 차단이 "진짜" 작동하는지 인과 확인

**[멘트]** "왜 이렇게 짰나"에 대한 답: 뒤집힘의 방향성·대조군·역방향 컨트롤이 전부 반증 가능성을 위해 존재.

## Slide 4 — 실행 방법과 신뢰성 장치 [요청 3]

**[헤드라인]** 구조적 차단(attention mask 등가)과 3중 sanity 게이트 위에서 6,000 forward를 실행했다

**[시각 1]** KV 차단 개념도: 좌 = layer 스택에서 layer L 이후 distractor 열이 회색 처리되는 그림 ("softmax 분모에서 제외 = 수학적으로 KV 부재와 동일, 근사가 아님"). 제안서 4페이지 그림 재활용 가능.

**[시각 2]** sanity 결과 미니 배지 3개:
```
T(0) vs S 일치율 98.3% (기준 90)  ·  S 정답률 85.5% (POPE 3B 보고치 부합)  ·  grounding 90% (기준 60)
```

**[텍스트]**
- 평가: 생성 없이 마지막 위치 next-token logit에서 Yes/No 비교 (토큰 id는 사전 확정·동결)
- 통계: 동일 문항 paired → exact McNemar
- 규모: 600문항 × 10조건 = 6,000 forwards + attention 프로파일링 600, RTX 3090 1장 · 총 29분 · seed 42

**[멘트]** "sanity 3종이 전부 통과했기 때문에 뒤의 숫자들을 믿을 수 있다"가 이 슬라이드의 존재 이유.

## Slide 5 — 결과 ①: 문제는 실재한다 [요청 4]

**[헤드라인]** distractor에 객체가 있을 때만 답이 뒤집힌다 — 셀1 21.3% vs 대조군 0%

**[시각]** Flip Rate 막대 4개 (셀1 21.3 강조색 / 셀3 0.0 회색 / 셀2 12.7 강조색 / 셀4 4.7 회색), 기준선 10%p 점선. 보조로 정답률 하락 화살표: 셀1 89.3→72.0 (−17.3%p), 셀2 74.0→63.3 (−10.7%p)

- 양방향(No→Yes, Yes→No) 모두 발생 + 대조군에선 없음 → **cross-image leakage의 직접 증거**
- 판정 ① PASS (사전 등록 3요건 전부 충족)

## Slide 6 — 결과 ②: 후반 layer 차단이 오염을 회복시킨다 [요청 4]

**[헤드라인]** L=4 차단으로 오염 오답의 81%가 회복되고, 연산은 42% 줄어든다

**[시각]** **fig1_accuracy_vs_L.png** (대표 그림 — 셀1·2 패널, `[EXT]` L 세분화 12점 버전으로 교체 예정). 그림 위에 콜아웃 3개: "T(0) 상한 0.933" / "M baseline 0.720" / "T4 = 0.920, 단일이미지 S(0.893)보다 높음"

**[텍스트]**
- L\*=4: Recovery 셀1 **81.0%** · 셀2 25.5% / Damage 3.7% · 1.1% → 부수 피해 없이 회복
- McNemar p = **6.0e-7** (셀1) / 9.8e-4 (셀2) — 양방향 모두 유의
- 이론 prefill FLOPs **42.4% 절감** (distractor 토큰의 32/36 layer 생략)

**[멘트]** "얕게 차단하는 것이 더 싸면서 더 정확하다" — 제안서 핵심 주장의 실측.

## Slide 7 — 결과 ②″ + 신규 발견: 인과 확인, 그리고 leakage는 '후반부'에서 일어난다 [요청 4]

**[헤드라인]** 원본을 차단하면 답이 distractor를 따라간다 (p=3.6e-38) — 그리고 오염은 layer 16 이후에서 발생한다

**[시각 1]** negative control 셀별 막대: M(0.79) vs T-rel8 — 셀1 0.24 / 셀2 0.03 / 셀3 0.98 / 셀4 0.76. 콜아웃: "모델의 답이 '보이는 이미지'를 그대로 따라감 = 차단은 구조적으로 완전"

**[시각 2]** fig1 셀1 곡선에 구간 주석: "L=4~16: T(0) 상한에 붙어 평평 (회복 유지)" → "L=20부터 하락" → 결론 박스: **"이미지 간 유해 혼합은 후반 layer(≥16)에서 발생 — depth별 leakage의 최초 측정"**

**[텍스트]**
- 신규 발견: 앞 16개 layer의 이미지 간 혼합은 무해 → 차단 시점을 뒤로 미룰 여지 (Phase 1 설계 근거)

## Slide 10 — 유력 후보 방법론 + Phase 1 → CVPR 계획 [요청 6]

**[헤드라인]** 실측이 가리키는 방법: "늦게 판정하고, 그 시점부터 차단한다" — 11월 CVPR 제출 역산 로드맵

**[시각 1]** 후보 방법론 비교표 (실측 근거 컬럼이 핵심):
| 후보 | 아이디어 | 실측 근거 | 성공 가능성 |
|---|---|---|---|
| **A. Late-gate 차단** (유력) | layer ~18-21에서 관련도 판정 → 그 시점부터 distractor 차단 | 신호 layer 21=99% · T20 recovery 50% (p=0.013) · 절감 ~21% | **높음** — 신호와 개입점이 같은 구간 |
| B. 신호 재설계 + 얕은 차단 | 얕은 층의 다른 신호(delimiter hidden state, attention entropy 등)로 L=4 차단 | L=4 차단이 최대 효과 (recovery 81%·절감 42%) — 신호만 확보하면 상한 | 중 — 신호 탐색 필요 |
| C. Oracle 응용 (백업) | 사용자가 대상 이미지를 지정하는 응용(referring QA 등)엔 컨트롤러 불필요 | 본 실험 수치가 그대로 적용 (81% 회복 + 42% 절감) | 확보됨 — 시스템/응용 논문 경로 |

**[시각 2]** 타임라인 (CVPR 2026-11 마감 역산):
```
8월          9월                10월              11월
컨트롤러 신호  방법 확정 +        baseline 비교      작성·제출
탐색 (A vs B) 7B/LLaVA-OV 확장   (FOCUS 등)+ablation
+ 순서뒤집기   MuirBench/MVH-Bench
```

**[텍스트]**
- 핵심 설계 과제: 신호 위치(layer ~21)와 최대 효과 개입점(L≤16)의 간극 — 후보 A는 간극을 없애는 설계, 후보 B는 상한을 노리는 설계
- 컴퓨트: 학습 없음, 총 400–1,000 GPU-hour (제안서 계획 유지)
