## A. do-no-harm + top-k — 여러 이미지가 모두 필요한 질문

지금까지 전부 "1장만 관련" 설정이었다. 실제 입력은 2장 이상이 필요한 경우가 흔하다.
`allof3_items` ("Do all of these images contain X?") 은 3장을 **전부** 봐야 답할 수 있다.

조건: M3 / B0..B2 (컨트롤러) / **PIPE1** (top-1만 남기고 나머지 읽기 차단) / **PIPE2** (top-2 유지)

| | 조건 | 해석 |
|---|---|---|
| **위험 확인** | AUC(PIPE1) < AUC(M3) 유의 | 무조건 적용은 해롭다 — **게이트가 반드시 필요** |
| **일반화 성공** | AUC(PIPE2) ≥ AUC(M3) (CI 하한 > −0.02) | top-k 유지가 다중 관련 상황의 답. 방법의 일반화 축 확보 |
| **일반화 실패** | PIPE2도 유의하게 낮음 | 이 방법은 단일 관련 상황 전용. **논문에서 범위를 그렇게 한정** |

## B. 통합 주장 — 우리 분해가 양 진영을 설명하는가

문헌이 갈려 있다: MIMIC은 이미지 간 attention을 **막고**, CAPL·SoFA는 **연다**. 양쪽 다 개선 보고.
우리 설명: 서로 다른 경로를 건드렸다 (혼합=도움, 읽기=해악). **이 설명은 아직 검정된 적 없다.**

조건 (pairs.csv 셀1·2): M / **MIMIC** (이미지↔이미지를 층 12~23 구간에서만 차단) /
XIMG0 (0층부터 전부 차단) / READ (우리)

| | 조건 | 해석 |
|---|---|---|
| **통합 성립** | M < MIMIC < READ, MIMIC−M CI 하한 > 0 | MIMIC식도 이득이나 읽기 차단이 더 낫다 — 우리 설명이 양쪽을 포섭 |
| **부분** | MIMIC ≈ M | MIMIC의 이득이 이 설정에 없다. 통합 주장 범위를 좁힌다 |
| **반증** | MIMIC > READ | 우리 처방이 최적이 아니다. **주장 수정** |

## 해석 제약

1. MIMIC 층 구간은 원 논문의 절대값(12~23)을 3B(36층)·7B(28층) 모두에 그대로 적용한다.
   층 수가 다르므로 **상대 위치가 다르다** — 이 한계를 논문에 명시한다.
2. A의 PIPE1/PIPE2는 컨트롤러 오판을 포함한 실현 조건이다(오라클 아님).
3. B는 이미지 2장이므로 MIMIC의 "이미지 간" = (이미지2 → 이미지1) 한 방향뿐이다.
