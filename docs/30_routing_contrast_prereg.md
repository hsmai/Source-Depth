# 경로 대비(routing contrast) 재현 — 사전 등록

작성 2026-08-14, **새 데이터 측정 전**. 실행 `scripts/34_routing_contrast.py`.

## 왜 필요한가

`docs/29`의 결과(조합 0.974, 4조건 유의)는 **기존 로그의 저장된 logit으로 계산한 사후 분석**이다.
4개 조건은 같은 300문항을 공유하므로 **독립 재현이 아니다.** 새 문항으로 다시 재야 한다.
그리고 β=1.0은 결과를 본 뒤 고른 값이므로, 사전에 고정해야 한다.

## 새 문항

기존 `pairs.csv`에 쓰인 이미지를 **전부 제외**하고 COCO val2014에서 새로 구성한다.
**적대 셀** (방해가 정답과 **반대** 방향으로 밈) — 기존 설계와 동일:
- 셀1형: 정답 "없다", 방해에 질의 객체 O — 100문항
- 셀2형: 정답 "있다", 방해에 질의 객체 X — 100문항

**대조 셀** (방해가 정답과 **같은** 방향으로 밈) — **이번에 새로 추가**:
- 셀3형: 정답 "없다", 방해에도 X — 100문항
- 셀4형: 정답 "있다", 방해에도 O — 100문항

합계 400문항.

## 측정 조건 (이미지 2장, 문항당 7회)

| 조건 | 마스크 | 용도 |
|---|---|---|
| `M` | 없음 | 기준 |
| `B0` | 이미지1 전면 차단 | 판별기(하나씩 빼보기) |
| `B1` | 이미지2 전면 차단 | 판별기 + 통째 차단 비교 |
| `READ1` | 질문 → 이미지1 차단 | 판별기가 1을 무관으로 볼 때의 양의 갈래 |
| `READ2` | 질문 → 이미지2 차단 | 양의 갈래 (오라클) |
| `XIMG` | 이미지 ↔ 이미지 차단 | **음의 갈래** |
| `NOISE2` | 이미지2를 픽셀 노이즈로 교체 | FOCUS 방식 대조군 |

3B·7B 각각 400 × 7 = 2,800회, 합계 5,600회.

## 사전 고정 사항

- **β = 1.0** (docs/29에서 두 모델 모두 최적이었으나, 여기서는 **조정 없이 1.0으로 고정**)
- 주 지표: 판별력 점수(AUC). 정답률은 보고하되 판정 근거 아님
- 조합식: `margin = (1+β)·margin(READ2) − β·margin(XIMG)`

## 판정 기준

**주 종점 (오라클 조건)**: `AUC(조합) − AUC(READ2)`

| | 조건 | 해석 |
|---|---|---|
| **통과** | **> 0 이고 95% CI가 0 배제**, 3B·7B 모두 | 경로 대비가 읽기 차단 단독보다 낫다 — 재현 성공 |
| **부분** | 한 모델만 충족 | 스케일 의존. 범위를 그 모델로 한정 |
| **실패** | 두 모델 모두 CI가 0 포함 | **사후 분석이 우연이었음. 주장 철회** |

**부 종점 1 — FOCUS 방식과의 직접 비교**
`AUC((1+β)·NOISE2 − β·M)` 대비 우리 조합이 높은가. 낮거나 같으면 "구조적 차별점"의 실익이 없다.

**부 종점 2 — 대조 셀에서 해롭지 않은가  ← 이번에 추가된 가장 중요한 검정**

음의 갈래(XIMG)가 유효한 이유는 그것이 **체계적으로 거꾸로 답하기 때문**이다(적대 셀에서 AUC 0.403).
그런데 이 반전은 **문항 설계의 산물일 수 있다** — 우리 적대 셀은 방해가 항상 정답 반대로 밀도록
만들어졌다. 방해가 정답과 **같은** 방향으로 미는 대조 셀에서는 XIMG가 오히려 맞히고,
빼기가 **손해**로 뒤집힐 수 있다. 아직 한 번도 측정하지 않았다.

| | 조건 | 해석 |
|---|---|---|
| **통과** | 대조 셀에서 `AUC(조합) − AUC(READ2)` 의 CI 하한 > −0.02 | 해롭지 않다 — 방법을 무조건 적용 가능 |
| **조건부** | 대조 셀에서 유의하게 음수 | **적대 문항에서만 유효.** 어느 쪽인지 미리 알 수 없으므로
자동 적용 불가 — 논문에서 범위를 그렇게 한정한다 |

이 검정이 실패하면 3단계(경로 대비)는 **방법이 아니라 진단 도구**로 격하해 보고한다.

**부 종점 3 — 판별기 포함 성능**
`B0`/`B1`로 무관 이미지를 판정한 뒤 그 예측에 따라 `READ1`/`READ2`를 선택해 조합.
오라클 대비 얼마나 남는가. 무개입(M)보다 낮으면 실현 불가로 보고한다.

## 해석 제약

1. β를 사후에 바꾸지 않는다. 1.0에서 실패하면 실패로 기록하고, β 탐색은 **별도 실험**으로 분리한다.
2. `XIMG`는 오라클 조건이다(어느 것이 방해인지 알아야 정의됨). 부 종점 2가 실현 가능성을 본다.
3. 실패 시 `docs/29`를 철회 표시하고 덱의 해당 슬라이드를 내린다.
