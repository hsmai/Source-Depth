# 기존 연구 직접 비교 (FOCUS식 · VCD식) — 사전 등록

작성 2026-08-23, **측정 전**. 실행 `scripts/38_baselines.py`.

## 왜

지금까지의 비교 대상은 T0(오라클 전면 차단)뿐이었다. **T0는 FOCUS가 아니다.**
"우리가 FOCUS보다 낫다"를 한 번도 재지 않았으므로, 현재 novelty 주장은 비교 근거가 없다.

## 방법 — 개입 수단만 바꾼 통제 비교

같은 문항(scale_auc_items, N∈{1,3}), 같은 N+1 반사실 논리. 다른 것은 **개입 수단 하나**:

| | 반사실 만드는 법 | 최종 출력 |
|---|---|---|
| FOCUS식 | 이미지 픽셀을 노이즈로 교체 (재인코딩) | 고른 것만 남기고 나머지 노이즈 |
| VCD식 | 전 이미지 노이즈 = 음의 기준 | (1+β)·M − β·ALLN, β=1 고정 |
| **우리** | attention 마스크로 열 차단 | 고른 것만 남기고 나머지 **읽기만** 차단 |

우리 쪽 수치는 `35_endtoend.py`(REAL_READ)·`24_loo_controller.py`(B{i})와 짝지어 분석한다.

## 판정 (주 종점: 3B·7B, N=3)

| | 조건 | 해석 |
|---|---|---|
| **통과** | AUC(REAL_READ) − AUC(FKEEP) CI 하한 > 0 | 마스킹이 픽셀 노이즈보다 낫다 — 핵심 주장 성립 |
| **동급** | CI가 0 포함 | 정확도는 동급. 차별점을 **비용·해석 가능성**으로만 주장 |
| **실패** | 유의하게 음수 | **FOCUS가 더 정확하다.** 그대로 보고하고 방법 주장을 철회, 기전 분석 논문으로 재포지셔닝 |

부 종점: ① 컨트롤러 판별 정확도 — 우리(마스킹) vs FOCUS식(노이즈). 노이즈가 더 정확하면
"모델 상대적 관련도" 주장의 근거가 약해진다. ② VCD식 대비.

## 해석 제약

1. **재구현 근사임을 명시한다.** 원 논문의 하이퍼파라미터·집계 방식을 그대로 옮긴 게 아니라,
   "N+1 반사실 + 개입 수단"만 통제한 비교다. 논문에는 이 한계를 그대로 쓴다.
2. 노이즈는 `Image.effect_noise(size, 64)`, 원본과 **같은 해상도** → 토큰 수 불변.
3. 실패 시 β·σ를 사후에 바꾸지 않는다.
