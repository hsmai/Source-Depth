# 부분 관련 — 사전 등록

2026-08-14, **결과 관측 전**. 실행 `scripts/32_partial_relevance.py`.

## 왜 이 실험인가

지금까지 설계는 이미지가 **100% 관련 or 0% 관련**이었다. 그 세계에서는 앞단 selector가
원리적으로 가능하다 — 넣거나 빼면 된다. 실제 응용(인터리브 문서·롱비디오·멀티모달 RAG)에서는
**부분 관련이 기본값**이다.

부분 관련 이미지 B에 대해 selector의 선택지는 둘뿐이다:
**포함**(오염 감수) 또는 **제외**(정보 손실). 우리에게는 제3의 선택지가 있다 —
**맥락으로 남기고 증거로만 차단.**

## 설계 (이미지 3장)

질문: `"In the first image, is there {obj}?"` (gt 균형, 각 150문항)

| 그룹 | 2번 이미지 | 3번 이미지 |
|---|---|---|
| **PART-hit** | 질의 객체가 **작게** 존재 (bbox 면적비 < 2%) | 무관 |
| **PART-miss** | 질의 객체 없음 (대조군) | 무관 |

면적비는 `instances_val2014.json` 의 `area / (width × height)` 최대값 기준.
**기존 '포함' 판정 규칙(면적 무관)은 변경하지 않았고**, 부분 관련 판정용 보조 인덱스만 추가했다.
풀 확인 완료: 문항 600개 중 599개가 부분관련 후보를 확보.

## 조건

| | 의미 | 대응하는 실제 정책 |
|---|---|---|
| `M` | 무개입 | selector **"포함"** |
| `DROP2` | 2번을 전면 차단 | selector **"제외"** |
| `READ2` | 2번을 질문만 못 읽게 (맥락 유지) | **우리 제3의 선택지** |
| `DROP3` / `READ3` | 3번(무관)에 동일 조건 | 참조 |

## 판정 기준 (사전 고정)

**주 종점**: PART-hit 문항에서 `AUC(READ2) − max(AUC(M), AUC(DROP2))`

| | 조건 | 해석 |
|---|---|---|
| **통과** | **> 0 이고 95% CI가 0 배제** | selection이 표현할 수 없는 우월 지점이 존재 → **"selection은 잘못된 추상"** 성립 |
| **실패** | CI가 0 포함 | 부분 관련에서도 포함/제외 중 하나가 최선 → 주장 철회, 범위를 이진 관련도로 유지 |

**부 종점**: PART-miss(대조군)에서는 위 우월 지점이 **없어야** 한다.
있다면 부분 관련 때문이 아니라 조건 자체의 부작용이므로 주 종점 해석이 무효가 된다.

## 해석 제약

1. DROP2·READ2는 **어느 것이 부분 관련인지 알려준 오라클 조건**이다. 판별기 포함 성능이 아니다.
2. 주 지표는 AUC. 고정 임계값 정확도는 보고하되 판정 근거로 쓰지 않는다.
3. 실패 시 벤치마크를 갈아타지 않는다. 실패로 보고하고 범위를 축소한다.
